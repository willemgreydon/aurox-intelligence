# /aurox-pr-review

Review the current git diff as if this were an enterprise fintech PR.

## Steps

1. Run `git status`.
2. Run `git diff`.
3. Identify changed domains.
4. Review architecture.
5. Review risk.
6. Review tests.
7. Review docs.
