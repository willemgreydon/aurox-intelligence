# Factor Models

## Core Factors

### 1. Momentum
- Price trend continuation

### 2. Value
- Undervalued vs intrinsic value

### 3. Size
- Small vs large cap performance

### 4. Volatility
- Low vs high volatility assets

### 5. Liquidity
- Ease of trading

- Developer activity
